# GMBL Synthetic gBlock Design System

Automated pipeline for designing synthetic DNA positive controls 
for bovine hereditary disease diagnostics.

## Features
- BioPython-based sequence design pipeline
- 5 bovine disorders (Brachyspina, CVM, HH1, HH3, HH4)
- Publication-ready figures and manuscript materials & methods
- Complete technical documentation and troubleshooting guide

## Quick Start
python3 gblock_complete_pipeline.py CVM ./output
